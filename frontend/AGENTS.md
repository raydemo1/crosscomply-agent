# Frontend working rules

- Before designing, reviewing, or changing any frontend UI, read [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md).
- Treat `DESIGN_SYSTEM.md` as the source of truth for layout width, typography, color, spacing, surfaces, report readability, responsive behavior, and accessibility.
- If a page needs a deliberate exception, document it in `frontend/design/pages/<page-name>.md` and explain why the exception is necessary.

# 案件详情：结论优先

已完成审查的案件详情以审查报告为默认视图。公共页头只展示案件标题、案件状态和默认折叠的五阶段案件进度；进度中的补充核实是条件分支，不使用固定完成比例。来自具体待核验批注的入口可直接打开原文并定位，不必先经过报告。

审查报告先回答法律问题，再说明未确认事实和结论使用边界。主要问题只呈现简短判断；可定位的问题链接到原文高亮，无法定位到单段原文的问题在报告中展开法律分析。法律依据按具体引用展开，不在报告中复制待核实清单或 Agent 技术日志。

原文审阅用于核对批注、继续追查和按段修改。选择段落并点击“准备修改”后，就地显示原文与建议文本对比；完整工作稿按需展开。冻结原件不可直接改写，修改需人工接受，并保留独立工作稿与历史版本。案件资料按材料与版本、审查与审计记录分层，详细记录默认折叠。申报人反馈和审核人引用核查分开，任何技术校验状态都不能替代法律结论或人工审批。

桌面端采用宽原文列和窄批注列；平板及移动端改为单列。正文维持设计系统的法律文本字号、行高和可读宽度，只有页面页头允许吸顶。

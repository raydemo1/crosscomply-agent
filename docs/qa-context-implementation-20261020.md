## 已实现

- `law_agent/llm/usage.py`统一记录模型请求的阶段、实际模型、输入、缓存命中/未命中、输出与推理token、耗时和首字延迟。普通与流式请求均采集，流式末尾usage单独保存。异常、截断及取消仍留记录；缺少usage为未知，不记成零费用。
- 用量记录只保留消息长度及散列用于前缀审计，不保存输入正文或私有推理。问答内部状态保存分阶段用量，公共问答响应和模型上下文均不携带这些统计。
- `usage_cost`以明确的模型、价格版本、币种及命中/未命中/输出单价核算。推理已包含在输出时不重复计费；记录不全时总金额为空并保留已知部分，拒绝用同一价格核算不同模型。生产代码未内置会过期的提供方单价。
- `agent_context.py`从模型证据投影移除分数、排名、检索器和重复的查询归属字段，完整服务端状态保留这些信息。原文、来源标识、版本、效力和引用资格继续传递，原有原生工具历史与增量合并方式不变。真实原文或资格变化仍会发送更新。
- `qa_context.py`按实际读取窗口提取带版本和字符位置的材料，合并已读重叠区间，不自动提供未读内容。追问可复用最近八轮中本轮仍选中相同版本的已读材料；替换版本或取消选择时不继承旧材料正文，也不提供依赖该旧材料的模型回答。
- 历史回答带原轮次ID和引用定位映射。旧引用只作为来源导航，不能直接替代本轮法源。原始用户陈述与模型回答分开表达，当前用户修正仍以本轮为准。
- 作答保留所选来源的doc_type、authority、citation_role和can_cite_clause，连同既有条款、版本与原文使用；界面不增加元数据。
- 问答finish将未知业务事实与evidence_gaps分开，预算耗尽也记为调查限制，不再伪装为待确认业务事实。作答输入明确交接建议不是事实或法源，工作事实投影缩为时点/地区线索，不覆盖原始材料。
- 问答提示区分用户已明确陈述与独立核验、未知与不成立，要求按需追溯影响当前结论的转引原文；没有固定条号、固定调查顺序或新增模型核验。
- 网页发现契约说明当前只覆盖允许的中国官方站点，结果返回实际允许域及线索身份。没有扩张允许域、变更检索数量、执行预算或检索排序。此前已统一的四查询上限保持不变。

正式审查只复用技术字段投影和用量采集，事实确认、完整报告核验上下文、引用资格和审批链路保持原有职责。没有加入兼容协议、定位模型、事实冻结或问答整改回调。

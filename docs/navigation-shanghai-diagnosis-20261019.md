# 上海案复跑失败诊断

检查对象：`data/review_runs/navigation_full_rerun_20261019/eval_shanghai_001/` 的冻结输入、最终报告、核验结果、Judge 输入及评分结果。仅静态检查；没有新增模型调用，没有修改评分或原始结果。

## 结论

本次 `overall_pass=false` 的直接原因是报告选择 `risk_level=medium`，与候选案例明确要求的 `insufficient_evidence` 不符。不是来源未发现、原文未返回或目录分页失败。与此同时，最终报告存在结构化字段与正文的不一致，不能将失败简单归为“评分太严”。

## 直接评分证据

- 案例 rubric 同时指定 `should_abstain=true`、`acceptable_outcomes=["insufficient_evidence"]`，并允许列明条件与待核事实。
- `agent_runner.py` 以 `risk_level == "insufficient_evidence"` 判断 abstention，并逐字检查允许的 outcome；最终 `medium` 因而触发 `expected_abstention` 与 `outcome_not_acceptable:medium`。
- 两项失败均源于同一个风险标签，不是两个独立法律错误。没有非法条款引用或缺失必需来源导致的失败。
- Judge 实际收到这两个 rubric 字段，仍给出所有语义维度通过，并称 medium 与条件化结论一致。确定性失败优先，因此总结果仍为失败。

## 报告本身的问题

1. **未能确定个案路径，却填写了 `legal_path`。** 最终报告列明行业、数据项、个人信息属性与数量、CIIO、重要数据状态均未知，结论也明确不能确认自由出境。`legal_path` 填入的却是涵盖多个互斥分支的办理判断流程。现行 Agent 指令要求“确定路径有已确认事实和核验法源才填写 draft.legal_path，否则 null”。条件说明可以写在正文，但不应因此将确定路径字段填满。
2. **中风险被程序进一步解释为证据充分。** `agent_tools.py` 直接用风险标签生成 `evidence_self_check.status`；本次实际输出为 `sufficient`，issues 和 triggered_reasons 均为空。前端将这两个值分别显示为“中风险”和“证据充分”。这会弱化正文中尚不能作出个案判断的限制。这里核实的是代码映射及冻结输出，未运行前端交互验证。
3. **风险边界仍有局部表述冲突。** 第一条说“清单内数据不能自由出境……须按第七条……或按第八条……”，第二条才说未确认第三至六条分支前不得直接作强制程序结论。已返回的第七、八条原文都明确保留第三至六条例外。应在同一句强制程序判断中保留前提，避免读者单独摘取第一条时得到过宽结论。这是表述一致性问题；整篇已写有例外，不能据此断言整篇完全遗漏豁免。

## 为什么门禁没有拦住

- 代码检查的是 `insufficient_evidence => legal_path 必须为空`，并没有对其他等级强制判断事实是否足以确定路径；非不足等级主要另查是否有可引用 claims。因此 `medium + 条件流程 legal_path + claims` 能通过结构检查。
- 核验器明确承认“只能给出条件性路径”，仍判 supported；其理由还指出 legal_path 开头限定非 CIIO，后面又保留 CIIO 分支，却将其视为不影响核心支持性的表述问题。
- 对 `risk_boundaries:0`，核验理由主动补上“并受第三至第六条衔接约束”，接受了依靠相邻条目补足条件的写法。
- 语义 Judge 认可正文保留不确定性。它的通过不等于风险字段符合案例要求，也没有消除确定路径字段的语义冲突。

以上可以证明门禁接受了什么，不能证明模型选择 medium 的内部动机。没有把猜测的模型思考过程当作诊断证据。

## 与目录问题的关系

本轮四次核心提交的核验上下文均包含上海 2025 版清单五个文本块；国家规定相关条款也已返回。该案没有调用章节节点浏览/精读，因而不能用本案证明新目录提高了自主定位能力，也没有证据把这次失败归因于目录不规范。

## 建议后续处理

先保持该次失败结果。按当前字段契约修正报告行为：无法确定个案路径时保留条件说明，legal_path 留空；不要以 medium 自动消解不足事实。针对上述冻结报告建立字段一致性复现，再讨论是否需要区分“法源充分”与“个案事实足够”。如果产品将来允许不确定事实下的条件报告使用独立风险等级，应统一调整生产语义与评测，而不是只放宽这一个候选案例。本次没有执行这些改动。

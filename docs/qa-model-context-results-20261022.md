# QA固定证据与原生历史对照结果

2026-10-22。16份固定证据回答、4次原生历史回放已完成。生产QA、正式审查和语料保持原状。

## 决定

**不将GLM-5.3替换为生产默认模型；不采用新的提示或范围过滤调优。**

GLM在预定目标错误上由基线3题降到1题，但新增了两类实质错误，并有2题引用标记失效，未满足“完整交付且没有新增实质错误”的采用门槛。按预定条件不进入8次完整留出题问答，未增加Judge、引用修复调用或失败补抽。

这是8道未经专业审定的诊断候选、每题每版本一次的结果，不是法律准确率、稳定性或模型能力上限结论。

## 固定证据比较

每道原题使用历史实际调查得到的全部证据，配一道人为更改关键事实的对应题；评分边界不进入模型请求。既有成功答案复用，失败和中断记录保留。

| --- | --- | --- | --- |

| 实际出境人数与敏感人数明确 | 无 | 无 | 基线附带把定位信息笼统等同行踪轨迹；不能称整题法律通过 |

| 持续精确定位、无合同采纳标准 | 无 | 无 | 两版都将标准措施明确列为参考，本次未复现旧目标错误 |

| 更正为集体合同未知、累计12万人 | 有 | 无 | 基线将无法确认并入不成立分支；GLM有一枚未登记引用 |

“目标错误无”只代表预先指定的问题未出现，不代表其他法律判断或交付通过。完整原句、理由、源依据及结果散列在`reviews.json`，原始回答不改写。

两项新增实质错误有明确输入/原文对照：

1. **机制及备案混用。** 规模未知题的GLM总结称“但那也需要在出境前完成合同签订/认证及向网信部门备案”，将认证与标准合同备案混为共同手续，并将普通信息低于100万的情形一概降为合同/认证，未保持不满10万人对应的免予分支。基线在该题保留了低人数免予，并仅要求标准合同路径备案。
2. **未知被写成未履行。** 已确认HR题的GLM写“个人信息保护影响评估（尚未完成）”，表格又写“未完成，需补做”；但输入只说是否完成尚未核实。告知事项也由未核实被写成“仅说明用途、需补全”。基线在该题要求核对，未断定已经未完成。

两处引用失败分别为`[[cite:4480afc]]`、`[[cite:7076f0a4]]`。前一处相对于已发标记漏字符，后一处不属于该请求登记表；未按编辑距离猜来源，也未追加模型补丁。正文仍完整保存并可判读法律目标。这是固定探针的首遍交付观察，不能把6/8直接当作含生产引用补丁的端到端成功率。

## 原生历史观察

四次均使用原模型，保留保存的原生消息、工具定义和历史；不人工总结、不移植给GLM。

| 原题 | 干净证据输入 | 原生历史回放 | 边界 |
| --- | --- | --- | --- |
| 规模未知 | 仍有规模推定 | 仍有，且写成“至少落在标准合同/认证区间” | 当前主提示匹配，但消息组织、历史中间判断及引用格式同时不同 |
| HR集体合同未知 | 将无法确认并入申报分支 | 机制分支保持，但扩展为制度须具体记载字段、接收方等核实项 | 主提示和旧引用协议与当前不一致，身份渲染失败 |
| 精确位置 | 标准措施另列参考 | 标准持续提示、最小调用进入“核心要求/特别要求”，未保持参考性质 | 当前主提示匹配；单次观察支持继续检查上下文使用，不证明因果 |
| 已确认HR | 免予及同意例外保持 | 主机制保持，但将未核实的告知事项写成当前只说明用途 | 主提示和旧引用协议与当前不一致，身份渲染失败 |

旧协议两题的`[依据N]`被现渲染器拒绝，单列为协议不兼容，不能当作法律判断失败。没有修改历史请求去迎合当前格式。

逐字原文的序列化子串审计中，四份历史大多数原文只出现一次，部分出现两次；不能未经验证就把“原文大量重复”称为原因。历史总字符更多，不等于每条法源被重复堆叠。消息组织、中间判断及工具说明的影响仍未被单独隔离。

## 优化方向收敛

| 项目 | 本轮决定与依据 |
| --- | --- |
| 原生工具、完整原文、来源版本/资格、工具引用标记 | 保留；仍是身份与数据契约基础 |
| 现有确定性引用归一和一次受限补丁 | 保留；本轮未测试补丁净收益，不因原始标记损坏增设语义核验 |
| 默认模型切换 | 不采用；目标错误减少但新增实质错误，交付门槛也未通过 |
| 重复法律判断提示与QA范围排除字段 | 仍是简化候选；本轮没有单变量消融证据，不直接删生产实现 |
| 新提示、扩大召回、更多检索轮次、答案重写 | 不增加；原文已存在时，两模型仍会错误使用前提和规则 |
| 上下文使用与调查阶段最早错误 | 下一优先项；精确位置题出现了干净输入较好、历史回放退步的观察 |

下一步应保持当前模型、任务和完整证据，先核对原始输入、工具结果、中间状态和最终请求之间是否存在身份或语义传递问题，再选一个能明确隔离的上下文呈现改动做小对照。不要直接删历史、人工总结替换原文，也不要把已有去重再次包装成新优化。若做范围字段简化，应独立于上下文呈现验证，不与换模型或新提示合并。

本轮完成的是评测与去留判断，没有得到可重复修复这些法律判断错误的生产候选，也没有据小样本宣布模型达到上限。

# 工具标记、程序编号与两类内容错误复核

2026-10-21。本轮实现问答引用协议改造，并复核“事实不足却给确定判断”和“推荐性标准被写成强制义务”的已保存轨迹。保留原有工作区改动，正式审查协议未改。

## 引用改造

参考 OpenAI 的 [Citation Formatting](https://developers.openai.com/api/docs/guides/citation-formatting)：可引用单元采用稳定来源标识，模型输出来源标记，由应用解析、解析来源信息及展示定位；该文档也以内容块作为常用引用粒度。这里采用适合当前 DeepSeek 路径的 ASCII 标记，未迁移接口，也不假定 OpenAI 专用标记在 DeepSeek 上具有同样效果。

现在的职责分工：

1. 受控原文和网页取得后，程序从原始身份生成稳定的 `[[cite:…]]` 标记，将其与法名、条款标签和原文关联提供。
2. 模型选择实际支持段落的资料，逐字复制相应标记；不生成展示序号、来源标题、版本、URL 或摘录映射。
3. 程序验证标记是否属于本轮可用资料，将它转换为既有前端接收的 `[依据N]`，从原始资料登记表填充对应来源信息。前端继续归并同文件片段并展示简约引用按钮。
4. 流式分片中暂未完整的标记先缓冲，不把内部标记展示给用户。完整回答中不存在或未闭合的标记仍报错，不猜测来源、不自动改写正文、不追加模型修订。

模型输出协议不再接受自编 `[依据N]`，没有保留旧输出格式的兼容路径。前端收到的数字标记是程序生成的既有展示格式。程序只转换引用标记，回答正文及原生思考、工具历史保持原样；没有增加交接摘要或新的作答阶段。

最终引用列表仍只保留正文实际使用的资料。材料归属、逐字材料摘录、查询时点、法源性质和引用资格保持原有检查。模型仍须选择支持结论的正确资料；程序生成编号不会自动验证法律推导或场景适用性。

## 完整预览的衔接修复

原失败题的《个人信息保护法》第五十六条已经以 131 字候选预览全文出现，却没有引用身份。现在仅在问答搜索中，对**预览已逐字包含完整受控单条条文**的情况登记为已取得原文，随后获得工具标记，避免为取得引用身份重复读取同一段全文。

条件由程序检查：有真实条号和原有条款引用资格；该条文只有一个完整 chunk；预览与该原文逐字一致；继续沿用检索已有的时点及范围过滤。没有扩大搜索数量，也没有把目录、截断预览、多片段中的一部分或实施参考升级成正式条文。完整内容已在原预览中提供，此处对齐其身份，不追加新来源调查。正式审查仍走原有路径。

## 为什么两类内容错误仍出现

### 日均量题：错误前提在写作前已经成立

复核 `qa_full_retest_20261021_native/eval_cross_border_001` 的原始输入与接口返回记录：用户只提供日均处理约 50 万用户、手机号及定位拟用于境外推荐优化，没有明确累计去重出境人数、CIIO 状态和定位精度。

模型在生成答案前已经把日均处理用户理解为每天都在出境的用户，并按非 CIIO 展开判断。它随后又意识到处理量不等于出境人数，最终却保留了“大概率需要申报”的开头、“你属于非关键信息基础设施运营者”及确定性人数推导。

因此这次不是工具漏传用户事实，而是**先补齐了未给定前提，后面的条件提醒未同步修正开头和主结论**。现有“结论先行”与条件分支原则没有被一致落实。不能通过把这些事实填进检索线索、固定为用户事实或新增正式事实确认表来修饰结果。本轮不为该题堆叠特定题目的禁令，也未宣称引用改造修复了事实推断问题。

### 精确位置题：把标准措施并入了法律后果

复核 `eval_sensitive_002` 的实际请求：GB/T 来源的 `citation_role=implementation_reference`、`can_cite_clause=false` 已提供，来源性质没有在程序中被升级。但模型安排回答时，把法定义务与标准中的持续提示、最小调用频率等措施放进同一“法律后果”清单，最终写成“具体义务”，没有交代其参考性质。

这属于**模型将标准原文中的要求转成了本案强制法律要求**。已有英文枚举和主提示没有阻止该行为；不能再笼统声称只要保留元数据就能修好。

本轮在问答原文旁增加程序生成的中文 `citation_usage`，明确实施参考、解释辅助和有范围限制的依据分别可作什么用途，并保留原文、原始资格。对于实施参考，明确其原文中的“应”不能单独用来认定本案法定义务；不统一改写标准条文，也不认为所有参考材料都只含建议。该改动改善信息表达，本轮未重跑精确位置题，尚无行为收益结论。

后续按要求已撤去该生成字段与用途说明，保留原始来源资格；通用规则及示例的试验结果见[后续记录](qa-general-reasoning-trial-20261021.md)，未采用候选生产提示。

## 工具契约

| 请求 | 返回 |
| --- | --- |
| `source_id` | 根目录；每页最多 30 项 |
| `source_id + parent_node_id` | 直接子目录；每页最多 30 项 |
| `source_id + node_id` | 节点及子节点原文；每页最多 5 块 |
| `source_id + article_no` | 指定条文原文；每页最多 5 块 |
| `source_id + chunk_id` | 同文档内该块及邻近原文；最多 5 块 |

四种定位参数互斥，不接受空定位参数和负偏移。章节和条文的 `offset` 是文本块偏移，目录的 `offset` 是直接子项偏移。文本块模式继续通过相邻块标识续读，不接受偏移。

目录项包含 `node_id`、`parent_node_id`、标题、路径、子项数、覆盖块数、首块 ID、原文预览及可用的条号。返回 `mode=outline`、`hits=[]`；即使浏览叶节点得到空目录，也不会标为正文。预览仅用于定位，最长 180 字。

需要续读时，观察中给出 `next_read_request`，保留来源、节点/条号选择和下一偏移。阅读历史保存实际返回的节点、文本块及下一偏移，现有 checkpoint 保存这些字段。重复的同位置请求在调用工具前拒绝；已浏览目录不阻止精读，父子章节之间的重叠原文按文本块 ID 合并。

目录和正文先经过同一时效过滤。节点 ID 绑定来源内容、审查日期、文档、路径与首次出现位置；日期、内容或来源改变后，旧节点拒绝使用，要求重新浏览。同名标题不跨已经结束的章节范围合并。无标题正文显示为“正文片段”，不推造章节。

每个实际工具调用计一次读取预算，包括失败调用；重复位置、未知来源等预检查拒绝不计读取次数。新任务默认 10 次，历史 checkpoint 已明确保存的预算保持原值。Agent 仍可直接按条号/文本块阅读，不强制逐层浏览。

对既有同意义务争议，只将个保法第十三条登记为明确的诊断目标。其他争点未新增推测性的目标标签。目标关联到具体文本块，并记录来源发现步骤、原文返回步骤、核验输入行号与时间，以及原始文件散列。

| 分类 | 快照数 | 含义 |
| --- | ---: | --- |
| 来源已发现，目标未返回 | 5 | 有继续定位的空间；不自动证明属于工具导航缺陷，争点规划也可能导致不读 |
| 目标已返回，已有报告复核错误 | 2 | 不能归因于目标原文未取得；报告错误不一定由该目标的理解直接造成 |
| 目标已返回 | 1 | 正确人数对照，不因其他案例错误将其判失败 |
| 记录不足以针对目标归因 | 5 | 未登记可靠目标，包括中断快照；不算导航失败 |

本批快照没有出现无法匹配当前语料的文本块或正文差异。脚本遇到这类差异会标记 `version_mismatch`，不会根据相似标题或条号悄悄重映射。脚本同时支持历史单项、当前批量的阅读记录，并识别尚未续读完成的请求。

这里的“已有错误”来自历史 AI 离线复核，不是法律专家审定。返回记录不能证明原文在后续每次模型上下文投影中均完整保留；本次不据此作推理或核验效果结论。

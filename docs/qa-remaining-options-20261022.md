# QA 剩余候选与浏览器诊断

## 当前结论

目前有可用的协议修复，尚无被证明稳定改善法律判断的新增候选。单题一次只能筛选，不能证明稳定性。不增加付费重跑。

## 已试过，不应改名再试

- 更换 GLM：固定证据目标错误减少，但新增实质错误与引用失败，未过门槛。
- 证据字段顺序前置资格：两题目标错误均保留，另有引用失败，不采用。
- 主提示压缩：两题目标错误均保留，答案反而更长，不采用。
- 最后重申问题、范围与完成规则：2026-10-21 已做固定历史及有限完整运行，未得到可采用收益；不能再说这些完全未测。
- 引用标记稳定化及一次受限补丁：已经实现；正文法律推导不由它修复。
- 提问工具：未知人数题提问、明确人数题直接回答，各一次。已修复界面自带“不清楚”与模型选项重复导致结构拒绝的问题；仍有冗余及法律判断式提问。

## 更值得保留的调整方向

将明确的身份、字段有效性、来源标记和展示去重交给确定性程序；未知业务事实通过用户补充获得；法律适用仍保留条件和来源性质，不能靠关键词规则把模型结论写死。不要新增答案重写、多模型Judge或扩大检索来掩盖现有错误。

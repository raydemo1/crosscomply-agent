# 原文导航与事实口径（2026-10-22）

两项均采用最小调整：现有检索、目录、精读及事实结构足够，不增加来源适用范围上下文包或新的事实系统。

## 原文入口

已取得证据的evidence_sources和未读keyword_candidates按来源提供outline_read_request，例如：

```json
{"outline_read_request": {"source_id": "本轮已发现的来源编号"}}
```

Agent可直接将请求放入read_evidence的read_requests中，读取同一来源根目录。来源编号、目录树、章节ID、续页、时点过滤、引用资格及读取预算继续使用原有实现。程序不判断章节是否属于例外，不归纳行业覆盖范围，也不选择法律分支。目录预览不成为法条证据，随后读取的非正式法源也不会升级引用资格。入口按来源提供一次，不在每个证据片段重复。

## 事实口径

ReviewFacts的年度普通/敏感人数和count_period增加明确的字段说明，FactLedgerEntry.status说明确认、抽取、待核和冲突的来源含义。正式审查主提示、QA主提示和核验器引用同一份FACT_USAGE_GUIDANCE，每份提示仅出现一次：

> 保留事实的原始表述、统计对象、期间及处理或出境口径。已明确的用户陈述作为注明来源的前提，申请人确认不等于独立核实；缺失保持未知，冲突保留各方来源和不同表述。日均处理量、预计量与实际累计出境人数分别使用，缺少同口径依据时不相互推算或替代。

原文明示全年估算时仍保留估算及其期间；没有年度人数就不因日均处理量填入年度人数。other仍表示明示的其他统计期间，unknown表示未明确，不新增枚举或强制转换。

此次仅调整说明，没有新增数字识别、人数换算、自动冲突判断、事实抽取调用或持久化台账。QA保留原始问题、材料和历史，不逐条生成事实账本。现有明确冲突识别代码不变。

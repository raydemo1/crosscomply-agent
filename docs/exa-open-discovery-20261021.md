# Exa 开放发现与查询执行修复

2026-10-21。沿用 Exa 与现有受控法律库，不切换 DeepSeek 搜索、不更换模型、不修改语料或索引。

## 已实施

- Exa 请求删除 includeDomains；公开网页不再按原有十一站点名单剔除。损坏 URL、非 HTTP(S) URL 和带用户名密码的 URL 仍不接收。
- 基于规范的官方域名识别，给候选的原始相关性排名小幅加权，最多提前一位；第三方来源保留。域名分类不代表已核验身份、法律效力或法条引用资格。
- 最多四条查询均会执行，使用有界并发，避免前一条查询凑够三条结果就跳过后续查询。
- 每个查询内部按请求数量取少量候选余量（max_results+2，最多八条），跨查询按轮次合并、按 URL 去重；最终总数不超过 Agent 指定的 max_results，不直接接收全部候选。
- Exa 改用项目已有 httpx，保留明确失败反馈，没有增加重试或替代供应商路径。
- 工具说明及 search_scope 同步改为开放搜索，并明确 excerpt 只是最多 1200 字符的搜索窗口，不代表读完整页或附件。
- WebFinding 根据 URL 生成 is_official 分类，不能由外部返回的布尔值覆盖。官方身份与引用资格分别处理。
- 正式审查拒绝把第三方 URL 提交为官方补库来源或登记到官方新法源影响字段。官方来源仍沿用原有内容解析、文种、发布机关、施行日期及人工处理规则，不因开放搜索就自动赋予正式法条资格。
- 问答网页引用继续保持 web 身份、can_cite_clause=false；未加入独立语义核验、整改或审批。
- 案件详情将“最新官方材料”改为“公开资料线索”，第三方结果标为调查参考；未修改布局或增加常驻元数据。

## Agent 可调的返回数量

问答及正式审查共用的 search_web 工具已增加 max_results 参数，表示本批全部 queries 去重后的最终结果总数上限，不是每个查询的数量。Agent 可选择 1—8 条，省略时默认三条；queries 仍最多四条，各自均会执行。删除了根据查询数量自动扩大最终结果上限的分支。

参数从原生工具 Schema 经 AgentDecision / QADecision、共用调查循环、ComplianceAgentTools 传到 WebResearch。工具结果记录 max_results 和 returned_count。非法数量在执行前拒绝，不自动改写参数；重复、空结果或资料不足时允许少于请求数，不为凑数增加请求。

每条 excerpt 仍最多 1200 字符，单批资料正文最多 9600 字符。八条是上下文控制上限，不是经过评测的最优数量；提示要求按争点、例外和版本比较所需选择，不要求用满。现有调查轮数、两次 Web 调用预算、引用资格与正式审查关卡不变。

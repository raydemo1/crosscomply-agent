# CrossComply 案例：企业采购境外 CRM / AI SaaS

本目录是一套可公开复现的**脱敏、虚构演示资产**，用于展示企业在境外 SaaS 上线前如何经过材料提交、事实确认、路径判定、补件整改、飞书审批和决策留痕。它不是法律意见、真实客户项目、模型评测集或生产配置。

## 演示故事

华辰智造（示例）有限公司拟采购托管于德国的 NimbusCRM AI。首次提交时，累计出境人数和重要数据状态未知，因此案件必须进入“待补件”，不能由模型推测，也不能直接送审。业务、安全、数据治理和法务补齐事实后，全国主路径候选为“个人信息出境标准合同或个人信息保护认证”；本案例选择标准合同路线，并在合同、影响评估和备案动作完成前给出“附条件通过”的审批演示。

## 目录

```text
cross_border_saas/
├── materials/                    # 脱敏原始材料
├── review/                       # 模型预抽取、人工确认、规则判定和整改闭环
├── approval/                     # 飞书审批演示脚本与回调事件样例
├── report/                       # 可用于报告渲染的结构化示例数据
├── bootstrap/                    # 官方来源最小清单，不含完整法源正文
└── walkthrough.md                # 从上传到报告校验的逐步演示说明
```

## 真实性与边界

- 所有企业、供应商、人员、编号和金额均为虚构；
- `model_pre_extraction.json` 是固定的演示输出，不表示当前模型在线运行结果；
- 只有 `human_confirmed_facts.json` 中逐项带确认角色、时间和材料定位的字段可视为本案例的人工确认事实；
- 未重新运行或修改仓库现有 82 场景评测，不产生任何新模型指标；
- `bootstrap/official_sources.csv` 只保留稳定 `source_id`、官方页面和演示用途，不复制完整本地语料；
- 目录中不包含 API Key、飞书密钥、真实审批实例 ID、真实个人信息或供应商机密。
